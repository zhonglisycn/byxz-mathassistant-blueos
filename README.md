# 理科助手 · vivo WATCH GT 2

数学助手移植到 vivo WATCH GT 2，跑蓝河 BlueOS 3，432×514 方屏；v2.0 起加入化学与物理，改名「理科助手」。

- 包名 `com.byxz.mathassistant`
- 产物：BlueOS Studio 打包出的 `.rpk`
- 功能：计算器、方程求解、函数图像、化学（118 元素分页卡片 + 摩尔质量）、物理（11 个常用公式 + 电路图）、生物（高中知识 6 主题）
- 手环版（Vela 快应用）：https://github.com/zhonglisycn/byxz-mathassistant

## 数学模块

**计算器**：四则、幂、取余、阶乘，常量 π e，sin cos tan asin acos atan √ ln log abs 等；
隐式乘法（`2π`、`3(4+5)`、`(1+2)(3+4)`）；边输入边给预览；精确形式（π、√2、分数）；
角度弧度切换；光标编辑；虚数和精确分数。v1.7 起新增 `ⁿ√`（n 次根）、`↑`（高纳德箭头，键盘只保留一个按钮）
和 `|x|` 绝对值；指数塔最多 10 层。

**方程求解**：一次、二次（含复根、顶点、韦达定理）、二元一次方程组（克莱姆法则）、
复杂自由式（分母含 x、指数/log/绝对值/多次根混合）和 5 次以上数值求根。自由式子会自动展开移项化成一般式再解；三次/四次先用有理根定理
找有理根并降次，剩余部分数值求根；自由式子还支持 `|x|`、`root(x,n)`、指数塔。
结果同时给「精确」和「小数」两行，全局开关只决定哪行在前/加粗。
数值求根要求收敛后 |f(根)| 足够小，所以 tan 的渐近线和 1/x 的极点不会被误报成根。

**函数图像**：12 个预设函数加自定义表达式；三档区间；y 轴按分位数裁剪后再留余量；
符号求导给出 f′(x) 并可以直接画；值表；取点读数。手环上没有 canvas，
曲线是按像素列聚成的竖段拼出来的，一列一段。

## 化学模块（v2.2.0）

- **118 元素分页卡片**：不再渲染整张 18 列表格（真机上滑动失灵、渲染压力大）。每页只渲染当前页卡片，
  默认 16 张/页、共 8 页；小字号 6 页、大字号 8 页。支持周期 1–7 快速跳页、上一页/下一页；点元素进全屏大号详情：中文名、原子序数、
  相对原子质量、常见化合价、周期/族、化学性质和相关化学方程式。
  性质和方程式数据取自参考包「轻元素 1.0.6」（用户提供并同意复用）。
- **摩尔质量**：自写化学式解析器，支持括号/方括号嵌套、前导系数、结晶水（`.` 或 `·`），
  例如 `Ca(OH)2`、`Al2(SO4)3`、`[Cu(NH3)4]SO4`、`CuSO4.5H2O`；结果给相对分子质量和元素计数。
- 输入用常用元素键盘；不常用的元素点「+ 元素」从周期表插入，118 种都能用。

## 物理模块（v2.4.0）

速度与加速度、牛顿第二定律、功和功率、欧姆定律、密度、压强、液体压强、理想气体、波速、
动能与重力势能、热量，共 11 个公式。每个公式列出带单位的字段，点字段用数字键盘输入，
按 `=` 直接给结果；常量 g=9.8、R=8.314。

### 电路图（v2.4.0）

- 4×4 节点电路板：先点一个节点，再点相邻节点放置导线、电池、灯泡、开关或电流表
- 求解器、元件符号与实物外观移植自 [circuit-lab](https://github.com/az7627/circuit-lab)（MIT）：自动判断串联/并联/断路/短路，计算干路电流；灯泡按功率点亮，电流表显示读数
- 点已有元件可替换/删除；开关可点按切换通断
- 模板循环：串联、并联、测电流，可直接改成自定义电路
- 右上「实物图」把同一连接换成实验器材图标 + 粗导线；点开关仍可切换通断

## 生物模块（v2.2.0）

## 计算与显示（v2.2.0）

- 设置分成「计算 / 显示 / 关于」三个分页；底部首页作者条已删除，作者保留在设置关于页。
- 函数图像不再自动绘制：首次进页也不画，改完参数按「绘制」才画。

## 数学内核增强（v1.8.x）

### 1. 全局开关改成跨页共享（修前置 bug）

BlueOS 打包器会把 `common/*.js` 各内联一份进每个页面 bundle，**模块单例在页面之间不是
同一个对象**——原先把 deg/exact/vib 放在 `app.js` 模块级变量里，设置页改完，计算器页
读到的仍是旧值。现在按 `gt2-chess` 的三通道做法重写：

- `src/common/core/share.js`：共享宿主挂在 `app.$def.maShared`，页面 `onInit/onShow`
  调 `appGlobal.bind(this.$app)` 接入；`app.ux` 的 `onCreate` 调 `appGlobal.init(this)` 建袋。
- `src/common/core/app.js`：读取顺序 = 共享宿主 → storage（键名不变：`ma_deg` /
  `ma_exact` / `ma_vib`）→ 本页副本；两条通道都拿不到时 `console.warn` 一次。
- **默认值显式生效**：角度关、精确关、震动开。三条兜底路径都会把默认值写进共享袋，
  首装不会读到"无值"（棋类踩过的坑）。

### 2. 计算上限与护栏

| 项目 | 上限 |
|---|---|
| 计算器表达式 | 2048 字符 |
| 自由方程 | 1024 字符 |
| 方程系数 | 256 字符 |
| 图像自定义表达式 | 1024 字符 |
| 分词 token 数 | 16384 |
| 括号/函数/幂嵌套 | 128 层 |
| 求值递归深度 | 4096 层 |
| 幂 / 箭头结果 | ≤ 1e308，超出 → `数值过大` |
| 阶乘 | 最大 5000；100! 以上分块计算并显示进度 |
| `a↑↑b` | b ≤ 10 且每步 ≤ 1e308（键盘只保留一个 ↑ 按钮） |

输入框/表达式内部**不截断**，只有显示层按窗口截断（`clipCursor` 保证光标可见，
`clipText` 保留尾部）；内部串仍是完整的。

### 3. n 次根 / 箭头 / 指数塔语法

| 写法 | 含义 | 例子 / 上限 |
|---|---|---|
| `root(x,n)` 或 `ⁿ√` 键 | n 次根，n 为非零整数 | `root(27,3)=3`、`root(-8,3)=-2`、`root(-4,2)=2i`、`root(16,4)=2`；n=0 报错 |
| `√x` | 等价 `root(x,2)` | `√9=3`、`√-4=2i` |
| `^` | 幂，右结合，**最多 10 层** | `2^3^2=512`、`2^3^2^2` 可用；超过 10 层报错 |
| `↑` | 同 `^` | `2↑10=1024` |
| `↑↑` | 四阶运算（tetration）；核心仍支持，键盘不单独给按钮，按两次 `↑` | `2↑↑3=16`、`2↑↑4=65536`；`2↑↑5` 精确到 19729 位 |
| `↑↑↑` | 五阶运算（pentation），核心保留，键盘不单独给按钮 | `2↑↑↑2=4`、`2↑↑↑3=65536`；更大的保留箭头表示 |
| `\|x\|` | 绝对值 | `\|−3\|=3` |

`↑`/`↑↑`/`↑↑↑` 彼此右结合：`2↑3↑2 = 2↑(3↑2) = 512`。
键盘上计算器新增 `ⁿ√`、`,`、`↑`；方程页与图像页也只有一个 `↑` 按钮，
另外保留 `|`、`x²`、`x³` 快捷键。

### 4. 方程结果双显示 + 求解加强

- 结果区同时给两行：`精确：x1 = -√3/2，x2 = √3/2` 与
  `小数：x1 = -0.8660254038，x2 = 0.8660254038`。全局「精确/小数」开关只决定
  哪行在前、哪行加粗；精确形式不可得时只显示小数并注明。
- 二次：保留 √/分数精确形式与复根。
- 三次/四次：先按有理根定理试 `x = p/q`（p 整除常数项、q 整除首项），找到后综合除法降次，
  剩余二次用求根公式（含复根）；降不动的用 4000 段扫描 + 二分，并用导数找"只碰不变号"
  的偶次重根。三次及以上都走数值法；自由方程不设次数上限（结果受求值上限约束）。
- 自由式子新增 `|x|`、`root(x,n)`、指数塔/指数方程；非多项式走数值求根，
  `x` 在分母时用多区间扫描，并用 |f(根)| 阈值过滤渐近线/极点。
- 精确行做了严格校验：`formatExact` 在计算器里允许 1e-6 的分数近似，
  方程结果要求精确串还原后与数值根差 < 1e-9，否则视为"精确不可得"。

### 5. 按键震动只能在设置页关

- 默认**开**；开关只在「设置（About）」页，计算器/方程/图像/首页都没有开关或快捷切换。
- 所有页面按键统一走 `appGlobal.tap()`，`tap()` 每次都读共享容器里的 `vib`；
  关闭后三页都不会调用 vibrator（测试用假 vibrator 计数断言）。
- 设置改动立即发布到 `$app.$def.maShared` 并写 storage，切页立即生效、重启保留。

## 跟手环版比改了什么

- 系统接口全换成蓝河的：路由 `@blueos.app.appmanager.router`、存储 `@blueos.storage.storage`、
  震动 `@blueos.hardware.vibrator.vibrator`，manifest 里对应 `blueos.*` 能力声明
- 角度制 / 精确 / 震动 / 理科页字号四个设置：v1.7 起从"普通模块单例"改成 `$app.$def.maShared`
  共享容器 + storage 兜底（模块单例跨页不是同一个对象，见上文"本次增强"）
- 尺寸按 432×514 方屏重排（原来按 212×520 胶囊屏做的），页面留白那三档设置删掉了
- 键盘从自动换行改成一行四个写死，不去赌运行时的 `flex-wrap`
- 表达式、采样点数、取点 x 各有输入键盘，顶栏下面一排常驻按钮唤出，一次只开一个
- 采样点数可调（20~401，默认 200），点数少了竖段自动加宽，曲线不会断成虚线
- 原工程的 `tools/check-ux.mjs` 搬了过来，补上对 `data:` 字段的识别

## 跑起来

```bash
pnpm i        # 只有 lint 依赖，不装也能在 Studio 里跑
pnpm test     # 内核测试（跑之前会给 util.js 打桩）
pnpm lint
```

开发用 BlueOS Studio 打开工程目录，预览设备选 watch-square；Studio 首次打开工程会生成
`.ide/settings.json`，把里面 watch-square 的分辨率改成 `432*514`，预览就和 GT2 一致。
打包在工具栏「打包」，首次要生成签名；装表用 OrbitV 蓝牙推 rpk。

也可以命令行打包（blueos-pack 是 Studio 自带的，不用另装）：

```bash
PACK="<Studio>/resources/app/extensions/blueos-debugger/node_modules/blueos-pack/bin/index.js"
node "$PACK" build   --device-type watch-square   # 调试包，免签名
node "$PACK" release --device-type watch-square   # 发布包，需要 sign/ 下的证书

# 首次出 release 包前，生成一对自签名证书（MSYS_NO_PATHCONV=1 别漏）：
MSYS_NO_PATHCONV=1 openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout sign/private.pem -out sign/certificate.pem -days 3650 \
  -subj "/C=CN/O=byxz/CN=com.byxz.mathassistant"
```

产物在 `dist/watch-square/debug|release/`：v1.6.0 时 debug 约 215KB、release 约 90KB；
v1.7.0（共享容器/上限护栏/n 次根/箭头/双显示）后 release 约 116KB；
v2.6.1 物理公式区/键盘也改成 flex 流式，release 约 279KB。
体积增长来自每个页面各自内联一份新增内核（平台机制），不是资源文件。

## 已知问题

- 只在模拟器和 GT2 真机上试过。存储和震动两个接口写的是最坏情况能降级的形式，
  哪台机器上不生效，改 `src/common/core/util.js` 和 `src/common/core/vib-backend.js` 就行
- 图像页的曲线和坐标轴是绝对定位拼的，其他机型上没验证
- 数值求根只找实根（三次/四次的剩余部分若有两共轭复根，二次分支会给出复根，
  更高次只报实根）；精确分数只在有理根/有理数运算下给
- 指数塔/箭头在真机上重点看错误提示是否可读、双显示两行是否放得下、跨页设置是否真生效
- 化学分页卡片（默认 8 页）在真机上重点看翻页/周期跳转、字号小中大切换；详情长文本滚动是否顺畅
- 大阶乘进度条、设置三个分页和生物长文本滚动是 v2.2 新增，重点真机确认
